## 🚀 Por trás do True

- Aplicativo desktop em **Rust + Tauri**, com interface em HTML, CSS e JavaScript
- Contas, licenças, pagamentos e ranking em **Supabase** (funções, banco e regras de segurança)
- Publicação automática por **GitHub Actions**, com atualizações assinadas digitalmente
